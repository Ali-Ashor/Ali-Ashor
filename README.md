# Ali Ashor Portfolio

Full stack portfolio: HTML, CSS, JavaScript frontend and a Node.js + Express backend.

## Run locally
```bash
npm install
npm start
```
Open http://localhost:3000

## Structure
- `server.js` Express server, `/api/projects` and `/api/contact`
- `public/` the website (index.html, style.css, script.js)
- `data/messages.json` contact messages (created automatically, git-ignored)
